# المنهجية — النسخة التنفيذية المختصرة

> **المرجع الكامل:** صفحة «المنهجية» في Notion — **v1.4**
> لو رقم النسخة هنا مختلف عن اللي في Notion، النسخة دي قديمة: حدّثها قبل أي شغل جديد.
> الملف ده بيغطي اللي بتستخدمه وإنت بتكتب كود بس. القرارات والوثائق مكانها Notion.

---

## قبل ما تبدأ مهمة (تعريف الجاهز)

- [ ] معايير قبول قابلة للاختبار
- [ ] الشاشة/السلوك واضح
- [ ] النطاق محدود (نص يوم)
- [ ] مرتبطة بالدورة الحالية
- [ ] مفيش اعتماد خارجي غير محسوم

## قبل ما تقفل مهمة (تعريف الخلاص)

- [ ] كود مدموج
- [ ] Unit test للجزء المنطقي
- [ ] مراجعة تمت
- [ ] CI أخضر
- [ ] معايير القبول متحققة
- [ ] الوثيقة المتأثرة محدَّثة

## قواعد الـ PR

- PR صغير: سقف ~٤٠٠ سطر
- عنوان واضح + `Closes #رقم`
- مفيش أسرار ولا مفاتيح في الكود — أبدًا
- أي endpoint جديد: حدّث عقد الـ API

## مسار الباجات

`Bug → Triage → In Progress → In Review → In QA → Done`

أي باج أمني = ليبل `security` + أولوية P0 + يرجع للتطوير فورًا.

## النشر

- [ ] Smoke test عدّى
- [ ] خطة رجوع موجودة
- [ ] تنبيه واحد بيوصل فعليًا
- [ ] Runbook محدَّث (لو فيه Agent مجدول)
- [ ] بطاقة الحالة في README محدَّثة

## حاجات ممنوعة

- ميزة ناقصة تعبر دورة
- إصلاح باج من غير إعادة اختبار
- دمج من غير CI أخضر
- أسرار في الكود أو في اللوج
